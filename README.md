# paradigma-towerdef

Proyecto personal para practica de conceptos de Programacion Orientada a Objetos.
El proyecto es acerca de un juego estilo "tower defese" no se ha aplicado una UI ya que es una incorporacion futura.
Como features interesantes de este proyecto se incluyen:
- La generacion de cada mapa se realiza de forma aleatoria para no repetir mapas
- El avance de los enemigos se ejecuta con hilos
- Se aplican conceptos fundamentales del paradigma
